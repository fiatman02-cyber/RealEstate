# เช็คลิสต์ SEO / WCAG / Responsive

ทำอะไรไปแล้ว และเหลืออะไร — ใช้ตรวจซ้ำทุกครั้งที่เพิ่มหน้าใหม่

## SEO

### ทำแล้ว ✅
- [x] `<title>` ไม่ซ้ำกันทุกหน้า ยาว 40–60 ตัวอักษร มีชื่อแบรนด์ต่อท้าย
- [x] `<meta name="description">` ไม่ซ้ำกันทุกหน้า
- [x] `<link rel="canonical">` ทุกหน้า (กันปัญหาเนื้อหาซ้ำ)
- [x] `lang="th"` บน `<html>` — บอก Google และโปรแกรมอ่านหน้าจอว่าเป็นภาษาไทย
- [x] Open Graph + Twitter Card ครบทุกหน้า (แชร์ลิงก์แล้วขึ้นภาพ)
- [x] Structured Data (JSON-LD):
      `WebSite` + `SearchAction` + `Person` + `ProfessionalService` ที่หน้าแรก,
      `ProfilePage` ที่ About Me, `WebPage` + `BreadcrumbList` ทุกหน้าอื่น
- [x] Breadcrumb ที่มองเห็นได้ + มี markup กำกับ
- [x] `robots.txt` (บล็อก `_partials/` ไม่ให้ index)
- [x] `sitemap.xml` ครบ 18 URL
- [x] มี `<h1>` เดียวต่อหน้า ลำดับหัวเรื่อง h1→h2→h3 ไม่ข้ามขั้น
- [x] HTML เชิงความหมาย: `header` `nav` `main` `section` `article` `aside` `footer`
- [x] URL อ่านรู้เรื่อง (`about-me.html` ไม่ใช่ `page2.html`)
- [x] ลิงก์ภายในเชื่อมกันครบ ไม่มีลิงก์เสีย (ตรวจแล้ว 17 ลิงก์)
- [x] รูปทุกรูปมี `alt` (ภาพประดับใช้ `alt=""` ตามหลัก)
- [x] ใส่ `width`/`height` ทุกรูป → คะแนน CLS ดี
- [x] `loading="lazy"` รูปใต้จอแรก, `fetchpriority="high"` รูป Hero
- [x] มีหน้า 404 ที่ช่วยผู้ใช้หาทางต่อ และตั้ง `noindex`
- [x] `rel="noopener noreferrer"` ทุกลิงก์ที่เปิดแท็บใหม่

### ต้องทำเมื่อขึ้นเว็บจริง ⬜
- [ ] เปลี่ยน `fiatkopong.com` เป็นโดเมนจริงทุกที่ (ดู CONTENT-TO-CONFIRM.md ข้อ 6)
- [ ] แปลง `og-default.svg` → PNG/JPG 1200×630 (Facebook/LINE ไม่อ่าน SVG)
- [ ] ติดตั้ง HTTPS (บังคับ — Google ให้น้ำหนัก และเบราว์เซอร์เตือนถ้าไม่มี)
- [ ] ส่ง sitemap เข้า Google Search Console
- [ ] ติด Analytics (แนะนำ Google Analytics 4 หรือ Plausible ที่เป็นมิตรกับ PDPA กว่า)
- [ ] เพิ่ม `Article` / `NewsArticle` JSON-LD ในหน้าบทความแต่ละชิ้น
- [ ] เพิ่ม `FAQPage` JSON-LD ในหน้า FAQ (มีโอกาสได้พื้นที่พิเศษบนหน้าผลค้นหา)
- [ ] เพิ่ม `Course` JSON-LD ในหน้าคอร์ส
- [ ] ตั้ง cache header ให้ไฟล์ CSS/JS/รูป (ให้คนที่โฮสต์ช่วยตั้ง)
- [ ] ทดสอบด้วย PageSpeed Insights และ Rich Results Test ของ Google

## WCAG 2.1 ระดับ AA

### ทำแล้ว ✅
- [x] ลิงก์ "ข้ามไปยังเนื้อหาหลัก" (skip link) ทุกหน้า — โผล่เมื่อกด Tab
- [x] วงแหวนโฟกัสเห็นชัดทุกองค์ประกอบที่กดได้ (`:focus-visible` เส้นหนา 3px)
- [x] ใช้งานด้วยคีย์บอร์ดได้ทั้งเว็บ — เมนู, แผนที่ Location IQ, รางวิดีโอ, ปุ่มปิดวิดีโอ
- [x] กด `Escape` ปิดเมนูมือถือและปิดเครื่องเล่นวิดีโอได้
- [x] `aria-expanded` / `aria-controls` ที่ปุ่มเมนู
- [x] `aria-current="page"` บอกว่าอยู่หน้าไหน
- [x] `aria-pressed` ที่ปุ่มสลับสถานะ (ตัวกรอง, ถูกใจ, โซนแผนที่, ช่วงเวลานัด)
- [x] `role="dialog"` + `aria-modal` ที่เครื่องเล่นวิดีโอ และคืนโฟกัสให้ปุ่มเดิมเมื่อปิด
- [x] `aria-live="polite"` ที่ข้อความผลลัพธ์ฟอร์ม — โปรแกรมอ่านหน้าจอจะประกาศให้
- [x] ทุกช่องกรอกมี `<label>` ผูกกัน (ที่ซ่อนใช้ `.sr-only` ไม่ใช่ `display:none`)
- [x] ข้อความ error ผูกกับช่องด้วย `aria-describedby` + `aria-invalid`
- [x] ไม่ใช้สีเป็นตัวสื่อความหมายเพียงอย่างเดียว (มีข้อความ/ไอคอนกำกับด้วยเสมอ)
- [x] `prefers-reduced-motion` — ปิดแอนิเมชันทั้งเว็บสำหรับคนที่ตั้งค่าไว้
- [x] เป้าแตะ ≥ 44×44 px บนอุปกรณ์สัมผัส
- [x] ตัวอักษรใช้หน่วย `rem` — ผู้ใช้ขยายฟอนต์ในเบราว์เซอร์ได้ไม่พัง
- [x] คอนทราสต์: ออกแบบให้ผ่าน AA — ใช้ `--gold-ink` (#6E4F06) แทนทองสว่างเมื่ออยู่บนพื้นขาว
- [x] `<svg>` ที่เป็นภาพประดับใส่ `aria-hidden="true"` ที่สื่อความหมายใส่ `role="img"` + `aria-label`
- [x] marquee โลโก้หยุดเมื่อเอาเมาส์ชี้หรือโฟกัส (เกณฑ์ 2.2.2 หยุดการเคลื่อนไหวได้)
- [x] ชุดโลโก้ที่ซ้ำเพื่อเลื่อนต่อเนื่อง ใส่ `aria-hidden` ไม่ให้อ่านซ้ำ

### ควรทำเพิ่ม ⬜
- [ ] ทดสอบด้วยโปรแกรมอ่านหน้าจอจริง (NVDA ฟรีบน Windows) อย่างน้อยหน้าแรก + ฟอร์ม
- [ ] วัดคอนทราสต์จริงทุกคู่สีด้วยเครื่องมือ (แนะนำส่วนขยาย axe DevTools ฟรี)
- [ ] ใส่คำบรรยาย (caption) ทุกวิดีโอที่มีเสียงพูด — เกณฑ์ 1.2.2
- [ ] เขียนเนื้อหาหน้า `accessibility.html` ให้จริง พร้อมช่องทางแจ้งปัญหา
- [ ] ถ้าเพิ่มกราฟที่ซับซ้อนขึ้น ต้องมีตารางข้อมูลหรือคำอธิบายเป็นข้อความคู่กัน

## Responsive

### ทำแล้ว ✅
- [x] Mobile-first เขียน CSS จากเล็กไปใหญ่
- [x] ทดสอบแล้วที่ 375px (มือถือ) และ 1280px (เดสก์ท็อป) — **ไม่มีการเลื่อนแนวนอน**
- [x] ตัวอักษรปรับขนาดอัตโนมัติด้วย `clamp()` ไม่ต้องเขียน breakpoint ซ้ำ
- [x] กริดใช้ `auto-fit` + `minmax` — ปรับจำนวนคอลัมน์เองตามที่ว่าง
- [x] เมนูเปลี่ยนเป็นลิ้นชักเลื่อนจากขวาที่ ≤1023px พร้อมล็อกการเลื่อนพื้นหลัง
- [x] ตารางและรางเลื่อนอยู่ในกล่อง `overflow-x` ของตัวเอง ไม่ดันหน้าเว็บ
- [x] แก้ปัญหาการตัดคำภาษาไทยกลางคำในหัวเรื่อง (ลดขนาดฟอนต์ + กำหนดจุดตัดด้วย `<br>`)
- [x] ใช้ `svh` แทน `vh` ที่ Hero — กันปัญหาแถบที่อยู่เว็บของ Safari บนมือถือ
- [x] มีสไตล์สำหรับสั่งพิมพ์ (ซ่อนเมนู/ปุ่มลอย และแสดง URL ของลิงก์)

### ควรทดสอบเพิ่ม ⬜
- [ ] แท็บเล็ต 768px และ 1024px (จุดที่เมนูสลับโหมด)
- [ ] มือถือจอเล็ก 320px
- [ ] iPhone Safari จริง (จุดที่มักเจอปัญหามากที่สุด)
- [ ] แนวนอนบนมือถือ (landscape)
