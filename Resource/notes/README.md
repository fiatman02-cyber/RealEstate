# โน้ตประจำโปรเจกต์ FiatKopong

โฟลเดอร์นี้เก็บ "ทุกอย่างที่ไม่ใช่โค้ด" ที่คุณต้องรู้เพื่อดูแลเว็บนี้ต่อเอง
อ่านตามลำดับนี้ได้เลย

| ไฟล์ | อ่านเมื่อ |
|---|---|
| [CONTENT-TO-CONFIRM.md](CONTENT-TO-CONFIRM.md) | **อ่านก่อนอย่างอื่น** — รายการข้อความที่ผมร่างไว้ให้ และต้องให้คุณยืนยันว่าตรงกับความจริง |
| [IMAGE-GUIDE.md](IMAGE-GUIDE.md) | จะเปลี่ยนรูป / หารูปใหม่ / เช็คเรื่องลิขสิทธิ์รูป |
| [VIDEO-GUIDE.md](VIDEO-GUIDE.md) | จะใส่วิดีโอจริงลงในห้องฉายและ Hero |
| [ARTICLE-POLICY.md](ARTICLE-POLICY.md) | จะเริ่มลงบทความ/สรุปข่าว — **สำคัญเรื่องลิขสิทธิ์** |
| [SEO-WCAG-CHECKLIST.md](SEO-WCAG-CHECKLIST.md) | ก่อนเอาเว็บขึ้นจริง และทุกครั้งที่เพิ่มหน้าใหม่ |
| [NEXT-STEPS.md](NEXT-STEPS.md) | อยากรู้ว่าเหลืออะไรต้องทำ และลำดับที่ควรทำ |

## โครงสร้างโฟลเดอร์รูป

```
Resource/images/
├── brand/       โลโก้ + favicon
├── portrait/    รูปตัวคุณ (ตอนนี้เป็น placeholder)
├── articles/    ภาพหัวบทความ
├── courses/     ภาพหัวคอร์ส
├── partners/    โลโก้พาร์ทเนอร์ (ตัวอย่าง)
├── video/       โปสเตอร์วิดีโอ
└── og/          ภาพสำหรับแชร์โซเชียล
```

## กฎเหล็กสามข้อของเว็บนี้

1. **ทุกตัวเลขต้องมีที่มา** — ถ้าอ้างที่มาไม่ได้ ไม่ต้องขึ้นเว็บ
2. **ไม่ก็อปเนื้อข่าวคนอื่นมาวาง** — สรุปด้วยคำพูดเราเอง + ลิงก์กลับต้นทางเสมอ
3. **ไม่ใส่วุฒิ ยศ หรือตำแหน่งที่ไม่มีจริง** — ความน่าเชื่อถือมาจากผลงานที่ตรวจสอบได้
