## ต้องแก้ก่อนขึ้นเว็บจริง (สำคัญ)

> **ห้ามลบข้อความนั้นออกจนกว่าจะเปลี่ยนเป็นตัวเลขจริงพร้อมแหล่งอ้างอิง**

### 2. เรื่องเล่าในหน้า About Me
ในไฟล์ `about-me.html` มองหาคอมเมนต์ `<!-- [ยืนยันข้อมูล] -->` จะเจอ 2 จุด

- **ย่อหน้าเปิด** — ผมเขียนว่าคุณทำงานกับข้อมูลดิบหลายทางและแปลงเป็นข้อสรุปให้ผู้บริหาร
  → ถ้าเนื้องานจริงต่างจากนี้ แก้ให้ตรง
- **ไทม์ไลน์ 4 ช่วง** — ผมตั้งใจใช้คำว่า "จุดเริ่มต้น / ก้าวเข้าสู่สายอสังหาฯ / ปัจจุบัน / ก้าวต่อไป"
  แทนการใส่ปี พ.ศ. เพราะผมไม่รู้ปีจริง → เติมปีจริงได้เลยถ้าต้องการ

### 3. รีวิวลูกค้า (Testimonials)
รีวิวทั้ง 3 ชิ้นใน `index.html` เป็นข้อความสาธิต **ต้องแทนที่ด้วยรีวิวจริง**
และต้องได้รับอนุญาตจากเจ้าของข้อความก่อนเผยแพร่ (ตัวย่อชื่อก็ยังต้องขอ)

ข้อความกำกับที่ผมใส่ไว้ท้าย section นั้นก็ต้องลบเมื่อเปลี่ยนเป็นของจริงแล้ว

### 4. คะแนน Location IQ
นี่คือฟีเจอร์เรือธง จึงเป็นจุดที่ความน่าเชื่อถือเสียหายง่ายที่สุดถ้าทำผิด
ก่อนเปิดใช้จริงต้องมี

- [ ] สูตรถ่วงน้ำหนัก 5 มิติ ที่เขียนออกมาเป็นเอกสารได้
- [ ] แหล่งข้อมูลของแต่ละมิติ + ความถี่ในการอัปเดต
- [ ] วันที่เก็บข้อมูลกำกับทุกคะแนน
- [ ] ข้อความระบุข้อจำกัด (เช่น "คะแนนนี้ไม่ได้ประเมินสภาพตัวอาคาร")

โซนที่ใส่ไว้แล้ว 5 โซน: สุขุมวิทตอนกลาง, พหลโยธิน–จตุจักร, ฝั่งธนบุรี–บางหว้า,
รังสิต–ปทุมธานี, EEC ชลบุรี/ระยอง — แก้ค่าได้ที่แอตทริบิวต์ `data-zone` ในไฟล์ `index.html`

### 5. โลโก้พาร์ทเนอร์
โลโก้ 10 อันใน `Resource/images/partners/` เป็นโลโก้สมมติที่ผมวาดขึ้นเอง
(NORTHBRIDGE, SIAM ESTATE, DATALYTIC ฯลฯ) ไม่ใช่บริษัทจริง

**การนำโลโก้บริษัทจริงขึ้นเว็บต้องได้รับอนุญาตเป็นลายลักษณ์อักษรก่อน** และ
การแสดงโลโก้ต้องไม่ทำให้เข้าใจผิดว่ามีความร่วมมือระดับที่ไม่มีจริง

### 6. อีเมลและโดเมน
| ค่าที่ใส่ไว้ | ต้องเปลี่ยนเป็น |
|---|---|
| `hello@fiatkopong.com` | อีเมลจริง (อยู่ใน footer ทุกหน้า + `_partials/footer.html`) |
| `https://fiatkopong.com` | โดเมนจริง (อยู่ใน canonical/OG ทุกหน้า + `robots.txt` + `sitemap.xml` + `_partials/build.sh`) |
| `https://www.facebook.com/FFiatKopong` | URL เพจจริง |
| `https://www.instagram.com/ffiatkopong` | URL IG จริง |

วิธีเปลี่ยนโดเมนทีเดียวทั้งเว็บ (รันในโฟลเดอร์เว็บ):

```bash
grep -rl "fiatkopong.com" --include="*.html" --include="*.txt" --include="*.xml" --include="*.sh" . | xargs sed -i "s|fiatkopong.com|โดเมนจริงของคุณ.com|g"
```

### 7. หน้ากฎหมาย 3 หน้า
`privacy.html`, `terms.html`, `accessibility.html` ยังเป็นโครงเปล่า
เนื้อหานโยบายความเป็นส่วนตัวควรให้คนที่รู้เรื่อง PDPA ตรวจก่อนเผยแพร่
เพราะเว็บมีการเก็บอีเมลผ่านฟอร์ม
