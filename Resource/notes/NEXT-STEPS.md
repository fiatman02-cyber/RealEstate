## ลำดับที่แนะนำ

### ระยะ 1 — ทำให้ขายได้ก่อน (สำคัญที่สุด)
หน้าที่มีผลกับรายได้ตรงที่สุด ทำสามหน้านี้ก่อนหน้าอื่นทั้งหมด

1. **`consult.html`** — จองคำปรึกษา
   มีอยู่แล้วในระบบ: ปุ่มเลือกช่วงเวลา (`.slots`), ฟอร์มที่ตรวจข้อมูลได้, panel
   ต้องเติม: ขั้นตอนการทำงาน, ราคา/ขอบเขต, สิ่งที่ควรเตรียมมาก่อนคุย, ปฏิทินจริง
2. **`courses.html` + `course-detail.html`** — คอร์สเรียน
   มีอยู่แล้ว: การ์ด (`.card`), ป้ายราคา (`.badge`), ภาพหัวคอร์ส 4 ไฟล์
   ต้องเติม: รายการคอร์ส, เนื้อหาแต่ละบท, ราคา, ตารางเรียน, เงื่อนไขคืนเงิน
3. **`contact.html`** — ฟอร์มติดต่อ + ลิงก์โซเชียล

### ระยะ 2 — ทำให้น่าเชื่อถือ
4. **`about-us.html`** — ที่มาธุรกิจ พันธกิจ พาร์ทเนอร์
   มีอยู่แล้ว: marquee โลโก้เลื่อน, `.partner-grid`, timeline
5. **`testimonials.html`** — รีวิวจริง (ต้องขออนุญาตเจ้าของข้อความ)
6. **`faq.html`** — ใช้ `.acc` (accordion จาก `<details>` ทำงานได้ทันทีไม่ต้องเขียน JS)
   **ต้องมีข้อหนึ่งที่อธิบายเกณฑ์ Credibility Score** — ดู `ARTICLE-POLICY.md`

### ระยะ 3 — ทำให้คนกลับมา
7. **`articles.html`** — รายการบทความ
   มีอยู่แล้วครบ: ตัวกรองหมวด + ช่องค้นหา (`data-filter-root`), การ์ดพร้อมคะแนน,
   ยอดวิว, ปุ่มถูกใจ — เหลือแค่เพิ่มการ์ดบทความจริงเข้าไป
8. **`article-detail.html`** — บทความฉบับเต็ม + กล่องแหล่งอ้างอิง + คอมเมนต์
   **อ่าน `ARTICLE-POLICY.md` ให้จบก่อนเขียนชิ้นแรก**
9. **`reports.html`** — คลังรายงาน + ตัวกรอง + แยกฟรี/สมาชิก

### ระยะ 4 — ฟีเจอร์เรือธง
10. **`location-intelligence.html`** — แผนที่เต็มจอ
    เป็นจุดที่จะทำให้เว็บนี้ต่างจากคู่แข่งชัดที่สุด แต่ก็เป็นจุดที่ต้องมีข้อมูลจริงรองรับ
    ห้ามเปิดจนกว่าจะทำครบตาม `CONTENT-TO-CONFIRM.md` ข้อ 4
11. **`dashboards.html`** — ตัวอย่างผลงาน + ฟอร์มขอ demo
12. **`products.html`** — หน้ารวมบริการ

## ระบบหลังบ้านที่ต้องต่อ

ตอนนี้ฟอร์มทุกฟอร์มแสดงข้อความ "ส่งเรียบร้อย" แต่ยังไม่ส่งไปไหนจริง

### ฟอร์ม — เลือกวิธีใดวิธีหนึ่ง
| วิธี | ข้อดี | ข้อเสีย |
|---|---|---|
| **Formspree / Basin** | ต่อเสร็จใน 10 นาที ไม่ต้องเขียนโค้ดหลังบ้าน | จำกัดจำนวนฟรี, ข้อมูลอยู่กับผู้ให้บริการ |
| **Google Forms ฝัง** | ฟรีไม่จำกัด ข้อมูลลง Sheet เลย | หน้าตาคุมได้น้อย |
| **เขียน API เอง** | คุมได้ทุกอย่าง | ต้องมีเซิร์ฟเวอร์และดูแลเอง |

แนะนำเริ่มที่ Formspree — เปลี่ยนแค่ `<form action="...">` แล้วลบ `data-validate` ออก
หรือเก็บ `data-validate` ไว้เพื่อให้ยังตรวจข้อมูลก่อนส่ง

### ยอดวิว / ปุ่มถูกใจ / คอมเมนต์
ต้องมีฐานข้อมูลจริง ทางที่เร็วที่สุดคือ

- **คอมเมนต์:** ใช้ Giscus (ฟรี ใช้ GitHub Discussions เก็บ) หรือ Disqus
- **ยอดวิว:** ใช้ตัวนับของ Analytics ที่ติดไว้ แล้วดึงมาแสดง หรือใช้ Supabase/Firebase
- **ปุ่มถูกใจ:** ต้องมี API เก็บยอด — Supabase มี free tier พอสำหรับช่วงเริ่มต้น

**ก่อนเปิดคอมเมนต์จริง** ต้องมีระบบตรวจก่อนแสดง — เว็บที่พูดเรื่องอสังหาฯ
มีความเสี่ยงเรื่องข้อความหมิ่นประมาทโครงการหรือบุคคล ดู `ARTICLE-POLICY.md` ข้อ 6

### ระบบสมาชิก (ถ้าจะทำ member-only)
ยังไม่มีเลย ต้องมี: ระบบล็อกอิน, ระดับสมาชิก, การชำระเงิน
แนะนำอย่าเพิ่งทำ — รอให้มีคนอ่านและมีรายงานสะสมพอสมควรก่อน
ช่วงแรกใช้วิธี "กรอกอีเมลแลกไฟล์" ไปก่อนจะคุ้มกว่ามาก

## สิ่งที่ผมออกแบบไว้แล้วแต่ยังไม่ได้ใช้

CSS พร้อมใช้ทันทีในหน้าถัดๆ ไป ไม่ต้องเขียนใหม่

| คลาส | ใช้ทำอะไร | ใช้ที่หน้าไหน |
|---|---|---|
| `.acc` `.acc__item` `.acc__q` `.acc__a` | Accordion (ใช้ `<details>` ทำงานได้เลยไม่ต้อง JS) | FAQ, รายละเอียดคอร์ส |
| `.chips` `.chip` + `data-filter-root` | ตัวกรองหมวด + ช่องค้นหา (JS พร้อมแล้ว) | บทความ, รายงาน |
| `.slots` `.slot` | ปุ่มเลือกช่วงเวลานัด (JS พร้อมแล้ว) | จองคำปรึกษา |
| `.report-cover` | ปกรายงานแบบ 3D | lead magnet, คลังรายงาน |
| `.partner-grid` | กริดโลโก้พาร์ทเนอร์แบบนิ่ง | About Us |
| `.search` | ช่องค้นหาพร้อมไอคอน | บทความ |
| `.timeline` `.tl-item` | ไทม์ไลน์ | About Us, รายละเอียดคอร์ส |
| `.badge--member` `.badge--free` | ป้ายแยกเนื้อหาฟรี/สมาชิก | คลังรายงาน |
| `.li` + `data-li` | วิดเจ็ต Location IQ (ย้ายไปหน้าเต็มจอได้เลย) | location-intelligence |
| `.on-light` `.on-sand` | สลับ section เป็นโหมดพื้นสว่าง | ทุกหน้า |
| `.video-frame` | กรอบวิดีโอพร้อมปุ่มเล่น | ทุกหน้า |
| `.prose` | จัดหน้าเนื้อหายาว | บทความ, หน้ากฎหมาย |

## วิธีทำหน้าใหม่ให้เร็ว

1. เขียนเฉพาะ "เนื้อกลาง" ของหน้าลงไฟล์ `_partials/body/ชื่อหน้า.html`
   (ไม่ต้องเขียน head/header/footer)
2. รัน `bash _partials/build.sh`
3. เสร็จ — เมนู, SEO, footer, ปุ่มลอย, เครื่องเล่นวิดีโอ ประกอบให้เองครบ

อยากแก้เมนูหรือ footer ทั้งเว็บ → แก้ที่ `_partials/header.html` หรือ `_partials/footer.html`
ครั้งเดียว แล้วรัน build.sh ใหม่
(ยกเว้น `index.html` กับ `about-me.html` ที่เขียนมือ — ต้องแก้ในไฟล์นั้นเอง)
