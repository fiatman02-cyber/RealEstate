# นโยบายเนื้อหาบทความ — อ่านก่อนลงข่าวชิ้นแรก

นี่คือโน้ตที่สำคัญที่สุดในโฟลเดอร์นี้ เพราะระบบดึงข่าวมาสรุปเป็นจุดที่
**ผิดกฎหมายได้ง่ายที่สุด** และเป็นจุดที่ทำลายจุดยืน "ตรวจสอบซ้ำได้" ของเว็บได้เร็วที่สุด

---

## 1. เส้นแบ่งที่ห้ามข้าม

| ทำได้ ✅ | ทำไม่ได้ ❌ |
|---|---|
| อ่านข่าวต้นทาง แล้ว **เขียนสรุปใหม่ด้วยถ้อยคำของตัวเอง** | ก็อปย่อหน้าจากข่าวมาวาง แม้จะแก้คำบางคำ |
| อ้างข้อเท็จจริงและตัวเลขจากข่าว (ข้อเท็จจริงไม่มีลิขสิทธิ์) | ก็อปโครงเรื่องและลำดับการเล่าทั้งชิ้นมาทั้งดุ้น |
| ยกคำพูดสั้นๆ ในเครื่องหมายคำพูด + ระบุที่มา | ยกคำพูดยาวเป็นย่อหน้า หรือยกเยอะจนแทนการอ่านต้นฉบับได้ |
| ลิงก์กลับไปหาข่าวต้นทางเสมอ | เอาข่าวมาลงแล้วไม่บอกว่ามาจากไหน |
| ใส่บทวิเคราะห์/ความเห็นของเราต่อท้าย (นี่คือมูลค่าที่เราเพิ่ม) | บอกว่าเป็นบทวิเคราะห์ของเรา แต่เนื้อหาคือข่าวคนอื่น |
| ใช้ภาพที่เราสร้างเอง หรือภาพ stock ที่ใช้ได้ | ดึงภาพจากเว็บข่าวมาใช้ประกอบ |

**หลักจำง่าย:** ถ้าคนอ่านสรุปของเราจบแล้ว **ยังอยากคลิกไปอ่านต้นฉบับ** = เราทำถูก
ถ้าอ่านของเราแล้วไม่ต้องไปอ่านต้นฉบับแล้ว = เรากำลังแทนที่งานเขาซึ่งเสี่ยงผิดลิขสิทธิ์

---

## 2. ขั้นตอนทำบทความหนึ่งชิ้น

1. **อ่านต้นทางให้ครบ** — อย่างน้อย 2 แหล่งถ้าเป็นเรื่องตัวเลข
2. **จดเฉพาะข้อเท็จจริง** ลงกระดาษเปล่า: ตัวเลข วันที่ ใครพูด — ปิดหน้าข่าวทิ้ง
3. **เขียนจากบันทึกนั้น** ไม่ใช่เขียนจากหน้าข่าว (วิธีนี้กันการก็อปโดยไม่รู้ตัวได้ดีที่สุด)
4. **เพิ่มสิ่งที่เขาไม่มี** — นี่คือเหตุผลที่คนควรอ่านของเรา เช่น
   - เทียบตัวเลขนี้กับปีก่อน / โซนอื่น
   - ชี้ว่าตัวเลขนี้ตอบอะไรได้ และตอบอะไรไม่ได้
   - แปลว่าอะไรสำหรับคนซื้อบ้านหลังแรก
5. **ให้คะแนนความน่าเชื่อถือ** (ดูข้อ 3)
6. **ใส่กล่องแหล่งอ้างอิง** ท้ายบทความทุกชิ้น
7. **ระบุวันที่เผยแพร่และวันที่แก้ไขล่าสุด**

## 3. เกณฑ์ให้ Credibility Score

ป้ายคะแนนบนการ์ดบทความจะไร้ความหมายทันทีถ้าเราให้คะแนนตามใจ
ใช้เกณฑ์นี้แล้วบันทึกเหตุผลไว้ทุกครั้ง

| คะแนน | ลักษณะแหล่งข้อมูล | ตัวอย่าง |
|---|---|---|
| **9.0–10** | ข้อมูลปฐมภูมิจากหน่วยงานที่มีหน้าที่เก็บข้อมูลนั้นโดยตรง เผยแพร่สาธารณะ ตรวจย้อนได้ | ประกาศราคาประเมินราชการ, สถิติจดทะเบียน, รายงานธนาคารกลาง |
| **7.5–8.9** | ข้อมูลจากหน่วยงานรัฐหรือสถาบันวิจัย แต่เป็นข้อมูลแปรรูปแล้ว หรือมีการตีความประกอบ | ดัชนีที่คำนวณโดยหน่วยงาน, รายงานศูนย์ข้อมูล |
| **6.0–7.4** | ฝ่ายวิจัยเอกชนหรือบริษัทที่ปรึกษา มีระเบียบวิธีเปิดเผย แต่มีผลประโยชน์เกี่ยวข้องอยู่บ้าง | รายงานตลาดของบริษัทที่ปรึกษาอสังหาฯ |
| **4.0–5.9** | ข่าวจากสื่อที่อ้างแหล่งได้ แต่แหล่งเดิมตรวจไม่ได้ / ไม่มีตัวเลขประกอบ | ข่าวที่อ้าง "แหล่งข่าวในวงการ" |
| **1.0–3.9** | ข่าวประชาสัมพันธ์ของผู้ขาย, โฆษณาแฝง, ข้อมูลจากผู้มีส่วนได้เสียโดยตรง | ข่าวเปิดตัวโครงการจากดีเวลลอปเปอร์ |

**หักคะแนนเพิ่ม** เมื่อพบข้อใดข้อหนึ่ง (−0.5 ถึง −1.5 ต่อข้อ)
- ไม่ระบุช่วงเวลาที่เก็บข้อมูล
- ไม่ระบุขนาดกลุ่มตัวอย่าง
- ตัวเลขขัดกับแหล่งอื่นโดยไม่อธิบาย
- ผู้เผยแพร่มีผลประโยชน์ทับซ้อนที่ไม่เปิดเผย

**สำคัญ:** ต้องมีหน้าอธิบายเกณฑ์นี้ให้คนอ่านเห็น (แนะนำใส่ไว้ในหน้า `faq.html`)
คะแนนที่ไม่มีเกณฑ์เปิดเผย = ความเห็นที่แต่งตัวเป็นข้อมูล ซึ่งคือสิ่งที่เว็บนี้ต่อต้าน

## 4. รูปแบบกล่องแหล่งอ้างอิง

ใส่ท้ายบทความทุกชิ้น คัดลอก HTML นี้ไปใช้ได้เลย

```html
<aside class="panel mt-7" aria-labelledby="src-title">
  <h2 id="src-title" style="font-size:var(--fs-h4)">แหล่งอ้างอิง</h2>
  <ul class="prose mt-4">
    <li>
      <a href="https://ต้นทาง.example/ข่าว" target="_blank" rel="noopener noreferrer">
        ชื่อบทความต้นฉบับ — ชื่อสำนักข่าว
      </a>
      <span class="xs muted">(เข้าถึงเมื่อ 20 ส.ค. 2569)</span>
    </li>
  </ul>
  <p class="xs muted mt-4">
    บทสรุปข้างต้นเขียนขึ้นใหม่ด้วยถ้อยคำของ FiatKopong ลิขสิทธิ์เนื้อหาต้นฉบับเป็นของผู้เผยแพร่แต่ละราย
    หากพบข้อผิดพลาดหรือต้องการให้แก้ไข ติดต่อเราได้ทันที
  </p>
</aside>
```

## 5. ถ้ามีคนแจ้งว่าเราละเมิด

1. **ตอบรับภายใน 24 ชั่วโมง** และซ่อนบทความชิ้นนั้นไว้ก่อนระหว่างตรวจ
2. เทียบข้อความของเรากับต้นฉบับทีละย่อหน้า
3. ถ้าซ้ำจริง → เขียนใหม่หรือลบ แล้วแจ้งผู้ร้องเรียนว่าแก้แล้ว
4. บันทึกเคสไว้ เพื่อปรับกระบวนการไม่ให้เกิดซ้ำ

การตอบเร็วและแก้จริง เสียหายน้อยกว่าการเงียบมาก

## 6. ระบบคอมเมนต์

ตอนนี้คอมเมนต์เก็บใน localStorage (คนอื่นไม่เห็น) เมื่อเปิดใช้จริงต้องมี

- [ ] คิวตรวจก่อนแสดง (moderation) — กันสแปมและกันข้อความหมิ่นประมาทโครงการ/บุคคล
- [ ] ปุ่มรายงานความเห็นไม่เหมาะสม
- [ ] ข้อความแจ้งผู้ใช้ว่าความเห็นเป็นของผู้เขียนเอง ไม่ใช่ของ FiatKopong
- [ ] เก็บ IP/เวลาไว้ตามสมควรเพื่อรับผิดชอบทางกฎหมาย และแจ้งไว้ในนโยบายความเป็นส่วนตัว
