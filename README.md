## เลือก Stack อะไร และทำไม

คุณบอกว่าไม่มีพื้นฐานเว็บมาก่อน อยากให้ตั้งต้นง่ายและแก้ต่อได้ง่าย
ผมเทียบสามทางเลือกให้ดู แล้วเลือกทางที่หนึ่ง

| | **HTML + CSS + JS ล้วน** ⬅️ ที่เลือก | Next.js / React | WordPress |
|---|---|---|---|
| ต้องลงโปรแกรมอะไรก่อน | **ไม่ต้องเลย** ดับเบิลคลิกไฟล์ก็เห็นเว็บ | ต้องลง Node.js, npm | ต้องมีโฮสต์ + ฐานข้อมูล |
| แก้ข้อความเองได้ไหม | **ได้ เปิด Notepad แก้ได้เลย** | ต้องเข้าใจ JSX/component | ได้ แก้ผ่านหลังบ้าน |
| ค่าโฮสต์ | **ฟรี** (GitHub Pages) | ฟรีได้ (Vercel) | ~150–500 บาท/เดือน |
| ความเร็วเว็บ | **เร็วที่สุด** ไม่มีอะไรมาคั่น | เร็ว แต่ไฟล์ JS ใหญ่กว่า | ช้าสุด ถ้าไม่ปรับแต่ง |
| SEO | **คุมได้ 100% ทุก tag** | ดี | ดี แต่ต้องพึ่งปลั๊กอิน |
| ความปลอดภัย | **ไม่มีอะไรให้แฮก** (ไฟล์นิ่ง) | ดี | ต้องอัปเดตปลั๊กอินตลอด |
| เหมาะกับตอนนี้ | ✅ | เมื่อมีสมาชิก/ระบบล็อกอิน | ถ้าอยากเขียนบทความผ่านหลังบ้าน |
| จุดอ่อน | เมนู/footer ซ้ำในหลายไฟล์ | ต้องเรียนเยอะกว่ามาก | ช้า + ค่าดูแลต่อเนื่อง |

**ข้อสรุป:** เริ่มด้วย HTML + CSS ล้วน เพราะคุณจะแก้เว็บเองได้จริงตั้งแต่วันแรก
โดยไม่ต้องเรียนอะไรใหม่ และผมแก้จุดอ่อนเรื่องเมนูซ้ำด้วยระบบ `_partials/` + `build.sh` แล้ว

**เมื่อไหร่ควรย้ายไป Next.js:** ตอนที่ต้องมีระบบสมาชิกจริง (แยกสิทธิ์ผู้ใช้ทั่วไป vs สมาชิก)
หรือมีบทความเกิน ~50 ชิ้นจนต้องมีระบบจัดการ ตอนนั้น HTML ที่เขียนไว้ย้ายไปใช้ต่อได้เกือบทั้งหมด

## เปิดดูเว็บบนเครื่องตัวเอง

**วิธีที่ 1 (ง่ายสุด):** ดับเบิลคลิกไฟล์ `index.html`
> ข้อจำกัด: บางเบราว์เซอร์จะบล็อกฟอนต์หรือ JS เมื่อเปิดจากไฟล์ตรงๆ

**วิธีที่ 2 (ตรงกับของจริง):** เปิดเซิร์ฟเวอร์เล็กๆ บนเครื่อง (ใช้ PowerShell ที่มีอยู่แล้วใน Windows)

```bash
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .claude/serve.ps1
```

แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:8099`
(กด `Ctrl+C` ในหน้าต่างนั้นเพื่อปิด)

## จะแก้อะไร แก้ที่ไหน

| อยากแก้ | ไปที่ |
|---|---|
| **สีทั้งเว็บ** | `assets/css/base.css` หัวข้อ 01 (บล็อก `:root`) |
| ฟอนต์ | `assets/css/base.css` ตัวแปร `--font-display` / `--font-body` |
| **เมนู** (ทุกหน้า) | `_partials/header.html` แล้วรัน `bash _partials/build.sh` |
| **Footer** (ทุกหน้า) | `_partials/footer.html` แล้วรัน build.sh |
| ข้อความหน้าแรก | `index.html` (เขียนมือ แก้ในไฟล์ตรงๆ) |
| ข้อความหน้า About Me | `about-me.html` |
| **คะแนน Location IQ** | `index.html` มองหา `data-zone=` |
| ตัวเลขสถิติหน้าแรก | `index.html` มองหา `data-count=` |
| ใส่วิดีโอจริง | `Resource/notes/VIDEO-GUIDE.md` |
| เปลี่ยนรูป | `Resource/notes/IMAGE-GUIDE.md` |
| เพิ่มหน้าใหม่ | ตาราง `PAGES` ใน `_partials/build.sh` + ไฟล์ใน `_partials/body/` |

### ตัวอย่าง: เปลี่ยนสีทองเป็นสีอื่นทั้งเว็บ

เปิด `assets/css/base.css` หาบรรทัดนี้

```css
--gold-500:#C9A227;   /* ทองหลัก — ใช้บนพื้นเข้มเท่านั้น */
```

เปลี่ยนรหัสสี → ทั้งเว็บเปลี่ยนตามทันที (ปุ่ม เส้น ป้าย ไอคอน กราฟ ทุกอย่าง)

> ⚠️ ถ้าเปลี่ยนเป็นสีสว่างขึ้น ต้องแก้ `--gold-ink` ให้เข้มพอด้วย
> เพราะตัวนั้นใช้กับตัวหนังสือบนพื้นขาว ต้องผ่านเกณฑ์คอนทราสต์ WCAG

## สิ่งที่ทำไว้ให้แล้ว

**ดีไซน์**
โทนกรมท่า + ทอง + ขาว · หัวเรื่อง serif เนื้อหา sans-serif · Hero แบบโรงหนัง
มีแสงไล่เฉดเคลื่อนไหว · ห้องฉายวิดีโอแบบแถวเลื่อนเหมือน Netflix ·
marquee โลโก้พาร์ทเนอร์ · แอนิเมชันตอนเลื่อนหน้า · ปุ่มลอย "จองปรึกษาฟรี"

**ฟีเจอร์**
Location IQ (แผนที่ให้คะแนนทำเล 5 มิติ — คลิก/กดคีย์บอร์ดได้) ·
Credibility Score แบบวงแหวน · ยอดวิว + ปุ่มถูกใจ · ระบบคอมเมนต์ ·
ตัวกรองหมวด + ช่องค้นหา · Market Snapshot + sparkline · ตัวเลขนับขึ้น ·
เครื่องเล่นวิดีโอ lightbox · lead magnet + สมัครรับข่าว · ฟอร์มที่ตรวจข้อมูลเป็นภาษาไทย

**SEO**
title/description ไม่ซ้ำทุกหน้า · canonical · Open Graph + Twitter Card ·
JSON-LD (WebSite, Person, ProfessionalService, ProfilePage, BreadcrumbList, SearchAction) ·
robots.txt · sitemap.xml 18 URL · HTML เชิงความหมาย · h1 เดียวต่อหน้า ·
ตรวจแล้วไม่มีลิงก์เสีย

**WCAG 2.1 AA**
skip link · วงแหวนโฟกัสชัดทุกจุด · ใช้คีย์บอร์ดได้ทั้งเว็บ · Escape ปิด modal/เมนู ·
ARIA ครบ (`aria-expanded` `aria-current` `aria-pressed` `aria-live` `role="dialog"`) ·
คืนโฟกัสหลังปิดวิดีโอ · รองรับ `prefers-reduced-motion` · เป้าแตะ 44px · สไตล์สำหรับสั่งพิมพ์

**Responsive**
Mobile-first · ตรวจแล้วที่ 375px และ 1280px ไม่มีการเลื่อนแนวนอน ·
ตัวอักษรปรับขนาดอัตโนมัติด้วย `clamp()` · เมนูลิ้นชักบนมือถือ ·
แก้ปัญหาการตัดคำภาษาไทยกลางคำในหัวเรื่อง
